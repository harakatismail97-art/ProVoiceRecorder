# Pro Voice Recorder

تطبيق أندرويد لتسجيل الصوت محلياً باللغة العربية وبواجهة داكنة.

## المزايا الحالية
- تسجيل صوت بصيغة M4A/AAC بجودة 44.1 kHz و192 kbps.
- إيقاف مؤقت ومتابعة التسجيل (Android 7+).
- حفظ التسجيلات داخل مساحة التطبيق.
- تشغيل التسجيلات ومشاركتها وحذفها.
- لا يحتاج اتصالاً بالإنترنت.

## البناء عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع.
3. افتح تبويب **Actions** وانتظر انتهاء مهمة **Build Android APK**.
4. افتح نتيجة التشغيل الناجحة ثم نزّل ملف APK من **Artifacts**.

## البناء محلياً
افتح المجلد في Android Studio أو AndroidIDE المتوافق مع Gradle، ثم نفّذ:
`gradle assembleDebug`

الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## ملاحظة
هذه نسخة أولى قابلة للبناء. قصّ المقاطع ودمجها وتصدير MP3 ليست مضافة بعد؛ الصيغة الحالية M4A/AAC.
